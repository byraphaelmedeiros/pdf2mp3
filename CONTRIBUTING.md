# Contributing Guidelines

Thank you for considering contributing to **pdf2mp3**!

## How to Contribute
1. Fork the repository.
2. Create a feature branch (`git checkout -b feature/my-feature`).
3. Commit your changes with clear messages.
4. Push to your fork and open a Pull Request.

## Code Style
- Follow [PEP 8](https://peps.python.org/pep-0008/) style guidelines.
- Use English for all comments, variable names, and documentation.
- Keep commits atomic and descriptive.

## Development Setup
To set up the development environment, install dependencies with:

```bash
pip install -r requirements-dev.txt
```

This will install both runtime and testing dependencies.

Run the test suite with:

```bash
pytest
```

## Reporting Issues
- Use the GitHub Issues tab.
- Provide clear steps to reproduce.
- Include environment details (OS, Python version).

We welcome all contributions — bug reports, feature requests, or pull requests!
